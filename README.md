## 📌 About the Project

Aura Beauty is a beauty and cosmetics shopping interface designed to provide a simple, elegant, and user-friendly shopping experience.

The project covers the complete customer journey, from onboarding and product discovery to wishlist, cart, payment, and order confirmation.

## ✨ Features

- User onboarding
- Login and Sign Up
- Product browsing
- Category-based shopping
- Wishlist
- Shopping cart
- User profile
- Payment flow
- Order confirmation
- Interactive prototype

##  Design Process

1. Planned the complete user flow
2. Designed the interface in Figma
3. Created reusable interactive components
4. Used Figma Variables for interactions
5. Focused on consistent layouts and visual hierarchy
6. Created an interactive prototype
