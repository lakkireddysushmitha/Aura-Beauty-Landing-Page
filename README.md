#  Aura Beauty Landing Page

A modern and elegant beauty & cosmetics UI/UX design created in Figma.

![Aura Beauty Landing Page](landing%20page.png)

##  About the Project

Aura Beauty is a beauty and cosmetics shopping interface designed with a
focus on clean visuals, simple navigation, and a user-friendly experience.

The project covers the complete shopping journey, from onboarding and
product browsing to cart, payment, and order confirmation.

##  Features

- User onboarding
- Login and Sign Up
- Product browsing
- Wishlist
- Shopping cart
- User profile
- Payment flow
- Order confirmation
- Interactive prototype
